# GTA VI News

Independent Turkish GTA VI news site built with Next.js and a Python news scraper.

[View project](https://gta6news-beta.vercel.app) · [Portfolio](https://zuzuverseweb.pages.dev/) · [Yusuf Bingöl](https://github.com/2u2udev)

## Overview

A fan-made news project with a Next.js frontend and a Python scraper. This is an independent project, not an official Rockstar Games product.

## Local development

```sh
npm ci
npm run dev
npm run build
```

Configure any required services and environment variables using the existing project documentation. Never commit credentials.
